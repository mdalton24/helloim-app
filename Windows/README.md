# Windows

Download [helloim.ai-Setup.exe](helloim.ai-Setup.exe) using **Download raw file**, then run it. This is the same v1.0.0 installer as the published GitHub release. Windows may show a SmartScreen prompt because it is unsigned.

The existing published Windows source is in [windows-source](windows-source/), including the Rust backend, UI, and icon tooling. Its existing development version labels are preserved.

See [SHA256SUMS](SHA256SUMS) to verify the installer.

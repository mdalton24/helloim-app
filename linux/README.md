# Linux

This folder contains the amd64 Debian package built on September 14, 2026.

Download [helloim.ai_1.0.0_amd64.deb](helloim.ai_1.0.0_amd64.deb) using **Download raw file**. On an amd64 Ubuntu/Debian system, open a terminal in the download folder and install it with:

```sh
sudo apt install ./helloim.ai_1.0.0_amd64.deb
```

Launch helloim.ai from the applications menu. This package installs the desktop application; it does not install an operating system.

See [SHA256SUMS](SHA256SUMS) to verify the installer.
